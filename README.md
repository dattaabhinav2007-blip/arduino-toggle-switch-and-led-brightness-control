# arduino-toggle-switch-and-led-brightness-control

Arduino Toggle Switch and LED Brightness Control

In this project, I worked on two simple Arduino UNO circuits to improve my understanding of switches, buttons, and LED control.

Projects

Toggle Switch LED Control

- Used a toggle switch to turn an LED ON and OFF.

LED Brightness Control with Two Buttons

- Used one button to increase the brightness of the LED.
- Used another button to decrease the brightness of the LED.

Components Used

- Arduino UNO
- Toggle Switch
- 2 Push Buttons
- LED
- Resistor
- Breadboard
- Jumper Wires

What I Learned

- How to read input from a toggle switch
- How to use multiple buttons in one Arduino program
- How to control LED brightness step by step
- Basic Arduino programming and circuit connections

This is part of my daily Arduino learning journey and hands-on practice with embedded systems basics.
